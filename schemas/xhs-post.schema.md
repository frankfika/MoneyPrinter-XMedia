# 小红书文案 Schema（短文助手 → publisher-xhs 或 Fang 手贴）

落盘到 `outputs/<MMDD>-<slot>/<topic>/xhs.txt`，纯文本 UTF-8。

格式（用空行分段，方便 Fang 手贴）：

```
<标题（一行）>
<空行>
<正文（多段）>
<空行>
<标签（用 # 开头，空格分隔）>
```

## 字段约束（脚本校验）
- 标题 ≤20 单位（汉字约 1、ASCII 约 0.5）
- 正文 300~700 字
- 标签 3~8 个
- 配图：同 `outputs/<MMDD>-<slot>/<topic>/screenshots/*.png`，≥2 张
- 无「AI 托管发文 / 自动发文」相关字眼
- 无 OpenCSG / 公司字样

## 示例（仅供格式参考，不是真出稿）
```
GPT-5 真免费了？我把 3 家对比了下
正文：……
正文：……
正文：……
# AI # GPT # 工具 # 测评 # 免费
```
