OpenCode 出事了：1.4% Console 用户的 OpenAI / Anthropic / Google 余额被刷。

事件链条比较有意思——
攻击者搞的是"蒸馏攻击"：不是直接偷模型权重，而是大规模调用 API 收集高质量输入输出对，用来训练自己的小模型。

但这次他们没用自己的 key，用的是真实付费用户的 BYOK 密钥——流量看起来像正常用户，反欺诈系统拦不下来，账单还挂在别人头上。

OpenCode 的官方说法是：一个正在退役的遗留系统被人访问了，里面存着 Console 工作区里绑定的外部 API key。本地开源版本不受影响，只影响云端 Console。

这件事有几个值得看的点：

1. 用订阅而不是用 key 的人，这次天然免疫。
2. 用第三方聚合 / 小服务商的人，BYOK 密钥泄露风险比想象中大。
3. 头部 AI 厂商的 token 现在更难被蒸馏，因为攻击者也不容易拿到稳定 key。

如果你最近收到 OpenCode / 类似工具的邮件说"你的 key 可能泄露"，建议先去各家后台作废旧 key、重新生成，再查一遍账单用量。
