AK 又一个新论文整理：Hybrid Reasoning Agents。

核心思路是把快思考 / 慢思考 / 工具调用混合在同一套 agent loop 里，根据任务难度动态挑路径 —— 比纯 CoT 或纯 ReAct 之类单一范式更灵活。

paper 和官方点子都在 HF papers 上，链接给到。

50 秒 demo 是 AK 自己剪的，挑了两个对照 demo 看「知道什么时候思考、什么时候直接干」。
